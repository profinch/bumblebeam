How the puzzle works

1 · From a key to an address

one way only

A private key is just a number. Multiplying the curve's starting point G by it gives the public key; two hashes of that give the address. Every step is quick forwards and, as far as anyone knows, impossible backwards: the only way from an address to its key is to try keys.

    Puzzle #N's key has exactly N bits, so it lies between 2N−1 and 2N−1. Try 3 (#2), 0xd2c55 (#20) or 0x349b84b6431a6c4ef1 (#70): each gives that puzzle's address.

    2 · Three ways to find a key

    raced live on your CPU

    Brute force needs only the address and tries keys in order: on average half the range. Baby-step giant-step and Pollard's kangaroo need the public key, and then about 2·√range steps: for a 40-bit range a million instead of half a trillion. BSGS pays with memory (a table of √range points), the kangaroo only keeps a few “distinguished” points it lands on.

    Brute forceneeds: the address–
    Baby-step giant-stepneeds: the public key, √range memory–
    Kangarooneeds: the public key, little memory–
    Each lane is the range from 2N−1 to 2N−1. Brute force fills it from the left; BSGS lays out its baby steps, then strides through in giant steps; the kangaroo's tame herd leaves marks where it lands on distinguished points, until a wild one lands on the same trail.

    3 · Why every fifth puzzle is different

    In 2019 the puzzle's creator spent a little from #65, #70, #75 … #160. A spend reveals the public key, so those puzzles fell to the kangaroo instead of brute force: #135 needs about 2·267 ≈ 3 × 1020 kangaroo jumps, against 2133 ≈ 1040 keys by brute force. That is why #120, #125, #130 and #135 were solved while #71 to #74, far smaller, are still open.

    For the others only the address is known, and brute force is all there is. Each bit doubles the work: #71 has four times the keys of #69, which fell to brute force in April 2025. Open puzzles with a known public key today: #140, #145, #150, #155, #160, the next candidates for a kangaroo pool.
